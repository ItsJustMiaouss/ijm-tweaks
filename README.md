## ⚙️ IJM's Tweaks

A Fabric mod that tweaks the client side of Minecraft.

![Mod configuration image](https://github.com/ItsJustMiaouss/ijm-tweaks/assets/59478524/16d5cc54-8786-46de-a113-85076e6a238d)

### 📌Features

- Force the game to have a dark loading overlay (force the black monochrome color).
- Automatically enable the auto-jump when you step on stairs.
- Allow the experience bar to show up in the creative gamemode.
- Reduce the particles when a block is broken.
- Change the opacity of the pumpkin overlay.
- Zoom by holding a keybinding.
- Lower the height of the fire overlay.
- Tweaks on the creative inventory.
- Add a message to open the screenshots folder after taking a screenshot.
- An option to render the hitboxes of the invisible entities when using F3 + B. Require to be OP and in a non survival-like gamemode on a dedicated server..
- A fullbright option that can be toggled with a keybinding.

> Note: Everything is configurable and can be toggled.
